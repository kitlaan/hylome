Magic Pencil — scan

Connect to the pencil (Vispek Magic Pencil, NT-BL-G1), run a scan, download the 22-channel CSV. The output is the same index,sample,reference format that scripts/vispek_client.py writes, so it feeds straight into scripts/match.py identify and scripts/analyze.py. Protocol: PROTOCOL.md. Requires Chrome (desktop or Android) and a secure context: HTTPS or localhost.
